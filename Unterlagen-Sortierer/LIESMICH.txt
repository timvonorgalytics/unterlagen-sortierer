UNTERLAGEN-SORTIERER
====================

Das Programm liest eingescannte Unterlagen (PDF, JPG, PNG), erkennt den
Dokumenttyp und den Namen und benennt die Dateien einheitlich um, z. B.:

    Scan_0001.pdf   ->   Mustermann_Erika_Antrag.pdf
    Scan_0002.pdf   ->   Mustermann_Erika_Kontoauszug.pdf

Alles läuft auf diesem Rechner. Es werden keine Daten übertragen,
eine Internetverbindung ist nicht nötig.


STARTEN
  Windows: Doppelklick auf "Unterlagen-Sortierer starten" (.bat).
           Das Programm öffnet sich in Microsoft Edge.
  macOS:   Doppelklick auf "Unterlagen-Sortierer starten.command".
           Das Programm öffnet sich in Chrome bzw. Edge.
           Beim allerersten Start ggf. Rechtsklick -> "Öffnen" wählen,
           weil macOS heruntergeladene Programme zunächst blockiert.


SO GEHT'S
  1. "Ordner wählen" klicken und den Ordner mit den Scans auswählen -
     oder die Dateien bzw. den ganzen Ordner einfach mit der Maus auf
     das Programmfenster ziehen.
     Beim ersten Mal fragt Edge, ob das Programm den Ordner bearbeiten
     darf: "Dateien bearbeiten" bzw. "Zulassen" wählen.

  2. Optional: Nachname und Vorname des Antragstellers eintragen.
     Dann erhalten alle Dateien diesen Namen. Sonst liest das Programm
     den Namen aus jedem Dokument.

  3. Das Programm liest alle Dateien (einige Sekunden pro Seite).

  4. Liste prüfen:
       Grün  "Sicher"        -> Vorschlag ist eindeutig
       Gelb  "Bitte prüfen"  -> kurz kontrollieren
       Rot   "Name fehlt"    -> Name von Hand eintragen
     Dokumenttyp und Name lassen sich in jeder Zeile ändern.
     Ein Klick auf das kleine Vorschaubild öffnet die Datei.
     Zeilen ohne Haken werden nicht umbenannt.
     Bei vielen Dateien hilft unten der Haken "Nur zu prüfende
     anzeigen": grüne, sichere Zeilen werden dann ausgeblendet.

  5. Unten rechts auf den Knopf klicken:
       "Umbenannte Kopien speichern" -> Kopien im Unterordner "umbenannt",
                                         die Originale wandern unverändert
                                         in den Unterordner "verarbeitet"
       "Dateien umbenennen"          -> die Originale werden umbenannt
     Die Auswahl treffen Sie oben rechts unter "Neuer Dateiname".

  Jeder Durchgang legt ein Protokoll (Protokoll_Datum.csv) in den Ordner.
  Es lässt sich mit Excel öffnen und zeigt alte und neue Dateinamen.

  Die umbenannten Dateien liegen als einzelne Dateien im Ordner und
  lassen sich von dort direkt per Drag & Drop in die eAkte ziehen.
  Mit dem Haken "Je Person einen Unterordner anlegen" entsteht pro
  Person ein eigener Ordner - praktisch, wenn Unterlagen mehrerer
  Personen in einem Durchgang verarbeitet werden.

MEHRERE PERSONEN UND LAUFENDER BETRIEB
  Ohne Namens-Vorgabe erkennt das Programm den Namen je Dokument -
  Unterlagen mehrerer Personen können also zusammen in einem Ordner
  liegen. Legt die Scannersoftware laufend neue Dateien ab, holt
  "Neue Dateien einlesen" nur die neuen dazu; bereits erledigte
  Zeilen verschwinden dabei aus der Liste.
  Der Scan-Ordner zeigt immer nur die offene Arbeit: Verarbeitete
  Originale liegen im Unterordner "verarbeitet". Auch nach dem
  Schließen und Neustarten des Programms wird deshalb nichts
  doppelt eingelesen. Soll eine Datei noch einmal verarbeitet
  werden: einfach aus "verarbeitet" zurück in den Ordner ziehen.

ERKENNUNGSREGELN ANSEHEN
  Der Knopf "Erkennungsregeln" oben rechts zeigt, an welchen
  Begriffen das Programm jeden Dokumenttyp erkennt. Ändern kann
  die Begriffe Ihre IT in der Datei regeln.js (siehe "Hinweise
  fuer die IT.txt").


STAPEL-SCANS TEILEN
  Stecken mehrere Dokumente in einer Datei (z. B. Antrag und
  Kontoauszüge in einem Scan), zeigt die Zeile "Teilen ..." an.
  Ein Klick öffnet alle Seiten als Vorschau; ein Klick auf eine
  Seite vergrößert sie. Das Programm schlägt Trennstellen vor;
  ein Klick zwischen zwei Seiten setzt oder entfernt eine
  Trennstelle. Leere Rückseiten (Duplex-Scan) werden erkannt und
  weggelassen - "behalten" holt sie zurück, "weglassen" entfernt
  auch andere Seiten. "In N Dateien teilen" erstellt für jeden
  Abschnitt eine neue PDF-Datei mit eigenem Typ und Namen.
  Das Original bleibt unverändert und wird nur abgewählt.

DATEIEN ZUSAMMENFÜHREN
  Gehören mehrere Dateien zusammen (z. B. einzeln gescannte Seiten
  eines Kontoauszugs): nur diese Zeilen ankreuzen und unten auf
  "Markierte zusammenführen" klicken. Es entsteht eine neue
  PDF-Datei mit allen Seiten; auch Fotos (JPG/PNG) werden als
  Seiten übernommen. Die Originale bleiben unverändert.
  "Verwerfen" entfernt eine neu erstellte Datei wieder aus der Liste.

PERSONENLISTE (optional)
  Eine CSV-Datei mit den Spalten Nachname;Vorname, z. B. aus Excel
  ("Speichern unter" -> "CSV (Trennzeichen-getrennt)").
  Das Programm ordnet dann jedes Dokument der passenden Person zu,
  z. B. bei Ehepaaren. Die Liste wird nicht gespeichert.


DATEINAME ANPASSEN
  Im Feld "Neuer Dateiname" können Sie die Bausteine frei kombinieren:
  {Nachname} {Vorname} {Dokumenttyp} {Datum} {Original}
  Die Einstellung bleibt für das nächste Mal erhalten.


AUSPROBIEREN
  Im Ordner "Beispiel-Scans" liegen fiktive Testunterlagen.


WENN ETWAS NICHT KLAPPT
  - Das Programm öffnet sich nicht in Edge:
    Rechtsklick auf app\index.html -> "Öffnen mit" -> Microsoft Edge
  - macOS meldet "kann nicht geöffnet werden":
    Rechtsklick auf "Unterlagen-Sortierer starten.command" -> "Öffnen"
    -> "Öffnen" bestätigen. Das ist nur beim ersten Start nötig.
  - "Dateien wählen" statt "Ordner wählen" wird angezeigt:
    Der Browser erlaubt keinen Ordnerzugriff. Die umbenannten Dateien
    werden dann als ZIP-Datei in den Download-Ordner gespeichert.
  - Schlecht erkannte Dokumente: Scans mit 300 dpi und gerade
    eingelegtem Papier liefern die besten Ergebnisse. Handschrift
    wird nur eingeschränkt erkannt.
